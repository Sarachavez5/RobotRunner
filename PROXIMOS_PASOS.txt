═══════════════════════════════════════════════════════════════
  📋 PASO 1: PROBAR EN NAVEGADOR (AHORA MISMO)
═══════════════════════════════════════════════════════════════

Abre tu terminal y ejecuta:

    npm run dev

Luego abre en tu navegador:
    http://localhost:3000

Prueba el juego:
- Presiona ESPACIO o toca la pantalla para saltar
- Esquiva las cajas rojas (obstáculos)
- Recolecta baterías naranjas (modo turbo)
- Llega a 3000 metros para ganar

═══════════════════════════════════════════════════════════════
  📱 PASO 2: GENERAR EL .AAB PARA PLAY STORE
═══════════════════════════════════════════════════════════════

Cuando estés lista para compilar:

1. Compilar el juego:
   npm run build

2. Sincronizar con Android:
   npx cap sync android

3. Abrir Android Studio:
   npx cap open android

4. En Android Studio:
   - Espera el Gradle Sync (barra de progreso abajo)
   - Build > Generate Signed Bundle / APK
   - Selecciona: Android App Bundle
   - Crea tu keystore (guarda las contraseñas!)
   - Selecciona: release
   - Click Finish
   - Espera 5-10 minutos

5. Tu archivo estará en:
   RobotRunner/android/app/release/app-release.aab
