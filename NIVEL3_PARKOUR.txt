  🎨 PLATAFORMAS
════════════════════════════════════════════════════════════════

COLOR: Verde (matching con el tema del nivel 3)
TAMAÑO: 120px x 20px
FÍSICA: Sólidas - el robot puede pararse encima
MOVIMIENTO: Se mueven con el scroll del juego

CARACTERÍSTICAS:
✓ El robot puede saltar y aterrizar en ellas
✓ Son inmóviles (fijas en su posición)
✓ Se destruyen cuando salen de pantalla
✓ Perfectamente alineadas para saltos precisos

════════════════════════════════════════════════════════════════
  ⚙️ DETALLES TÉCNICOS
════════════════════════════════════════════════════════════════

ACTIVACIÓN:
• Se activa automáticamente a los 2200 metros
• Mensaje en consola: "🎮 Parkour activado en nivel 3!"

SPAWN RATE:
• Obstáculos normales: Cada 3.5 segundos (más espaciados)
• Secuencias de parkour: Cada 4 segundos
• Bien balanceado para no abrumar

FÍSICA:
• Colisión robot ↔ plataformas: Activada
• Gravedad en plataformas: Desactivada
• Inmóviles: Sí (el robot no las empuja)

════════════════════════════════════════════════════════════════
  🎮 EXPERIENCIA DE JUEGO
════════════════════════════════════════════════════════════════

NIVEL 1 (0-1000m):
  ✓ Saltos simples
  ✓ Obstáculos individuales
  ✓ Aprendizaje básico

NIVEL 2 (1000-2000m):
  ✓ Mayor velocidad
  ✓ Patrones de obstáculos
  ✓ Más desafiante

NIVEL 3 (2000-3000m):
  ✓ Al principio: Obstáculos normales (familiarización)
  ✓ A los 200m (2200m total): ¡PARKOUR!
  ✓ Plataformas verdes aparecen
  ✓ Saltos entre plataformas
  ✓ Obstáculos imposibles sin plataformas
  ✓ Baterías en lugares altos (recompensa)
  ✓ SE SIENTE COMPLETAMENTE DIFERENTE

════════════════════════════════════════════════════════════════
  🚀 CÓMO PROBAR
════════════════════════════════════════════════════════════════

1. Recarga el navegador (F5)
2. Juega hasta llegar a 2000 metros
3. Verás "¡NIVEL 3!" (fondo verde)
4. Juega 200 metros más (hasta 2200m)
5. ¡Aparecerán las plataformas verdes!
6. Salta de plataforma en plataforma
7. Busca la batería en la plataforma alta

════════════════════════════════════════════════════════════════
  ✨ DIFERENCIAS CON NIVEL 1 Y 2
════════════════════════════════════════════════════════════════

NIVEL 1:
  • Solo obstáculos en suelo o flotantes
  • Saltas SOBRE los obstáculos
  • Lineal

NIVEL 2:
  • Obstáculos en patrones
  • Mayor velocidad
  • Más patrones pero mismo concepto

NIVEL 3:
  • PLATAFORMAS PARKOUR
  • Saltas ENTRE plataformas
  • Vertical (subes y bajas)
  • Obstáculos que REQUIEREN plataformas
  • Baterías como recompensa por parkour
  • Totalmente diferente mecánicamente
